# 2.2 JavaScript의 현황

## 브라우저 밖으로 확장된 JavaScript

JavaScript는 처음에 브라우저에서 실행되는 클라이언트 측 스크립팅 언어로 시작했다.
오늘날에는 프론트엔드를 넘어 여러 분야에서 사용하는 범용 언어로 발전했다.

이 변화의 중심에는 **Node.js**가 있다.
Node.js는 브라우저 밖에서 JavaScript를 실행할 수 있게 해주는 런타임이다.

Node.js가 등장하면서 JavaScript 하나로 프론트엔드와 백엔드를 모두 개발할 수 있게 되었다.
개발자는 여러 언어를 오가는 부담을 줄이고 전체 시스템을 일관된 언어로 이해할 수 있게 되었다.

## Java와 Node.js에 대한 인식

한국 개발 현장에서는 다음과 같은 말이 종종 사용된다.

> 대기업은 Java를 사용하고 스타트업은 Node.js를 사용한다.

대기업에서는 오랫동안 Java와 Spring을 사용해 왔다.
공공기관과 엔터프라이즈 시스템에서도 Java 기반 기술이 널리 사용되었다.
그 결과 Java를 경험한 개발자도 많다.

스타트업에서는 빠른 개발 속도와 팀의 유연성을 중요하게 생각하는 경우가 많다.
프론트엔드 개발자는 익숙한 JavaScript로 서버와 API와 데이터베이스를 다룰 수 있기 때문에 Node.js를 선택하기도 한다.

물론 모든 대기업이 Java를 사용하거나 모든 스타트업이 Node.js를 사용하는 것은 아니다.
프로젝트의 목적과 팀의 경험에 따라 기술을 선택한다.

## ES6+와 현대 JavaScript

JavaScript는 ECMAScript 사양을 바탕으로 표준화되며 발전해 왔다.

ES6에는 다음과 같은 문법이 도입되었다.

- `let`과 `const`
- 화살표 함수
- 클래스
- 템플릿 리터럴
- 모듈 시스템

ES6 이후에 추가된 기능을 통틀어 **ES6+**라고 부른다.
이 문법들은 코드의 재사용성과 유지보수성을 높여 주었다.

React 개발에서는 다음 문법을 자주 사용한다.

- `map`과 `filter`
- 구조 분해 할당
- 스프레드 연산자
- 화살표 함수
- `async`와 `await`

## 핵심 정리

JavaScript는 브라우저 안에서만 사용하는 언어가 아니다.
Node.js와 현대적인 ECMAScript 문법을 바탕으로 웹 개발 전반에서 사용하는 언어로 성장했다.
