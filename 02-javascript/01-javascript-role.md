# 2.1 JavaScript의 역할

## 웹을 구성하는 세 가지 기술

웹 프론트엔드는 주로 HTML과 CSS와 JavaScript로 구성된다.

- **HTML**은 콘텐츠의 구조를 정의한다.
- **CSS**는 콘텐츠의 모양과 배치를 담당한다.
- **JavaScript**는 사용자와 상호작용하고 화면을 동적으로 바꾼다.

JavaScript는 처음에는 웹페이지에 간단한 동작을 추가하기 위해 만들어졌다.
지금은 웹 개발 전반에서 사용하는 핵심 언어로 발전했다.

## JavaScript의 활용 분야

### 프론트엔드

- HTML 요소를 조작한다.
- 사용자의 이벤트를 처리한다.
- 상태 변화에 따라 화면을 갱신한다.

### 백엔드

Node.js를 사용하면 JavaScript로 서버를 만들 수 있다.
API를 구축하고 실시간 기능을 구현할 수도 있다.

### 모바일 앱

React Native와 Expo와 Ionic 같은 도구를 사용하면 iOS와 Android 앱을 만들 수 있다.

### 데스크톱 앱

Electron과 Tauri를 사용하면 Slack과 VS Code 같은 데스크톱 앱을 만들 수 있다.

### 테스트와 자동화

Playwright와 Puppeteer로 브라우저를 자동화할 수 있다.
Jest를 사용하면 단위 테스트를 작성할 수 있다.

### 디자인 도구와 AI 도구 연동

Figma 플러그인과 AI 코드 도구의 기능을 JavaScript로 확장할 수 있다.

## React와 JavaScript

React는 JavaScript 위에서 동작하는 UI 라이브러리다.
JSX도 JavaScript를 확장한 문법이다.
따라서 JSX 안에서 사용하는 표현식은 대부분 JavaScript 문법을 따른다.

React 문법을 빠르게 익히려면 먼저 JavaScript를 정확하게 이해해야 한다.
변수와 함수와 배열과 비동기 처리 같은 기초가 React 코드의 바탕이 되기 때문이다.

## 핵심 정리

JavaScript는 웹 화면에 동작을 더하는 언어에서 출발해 다양한 플랫폼과 도구를 만드는 범용 언어로 발전했다.
