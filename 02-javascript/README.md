## 핵심 내용

### JavaScript의 역할

- HTML은 화면의 구조를 만든다.
- CSS는 화면의 모양을 꾸민다.
- JavaScript는 화면의 동작을 만든다.
- JavaScript는 브라우저뿐 아니라 서버와 모바일 앱과 데스크톱 앱에도 사용할 수 있다.
- React와 JSX도 JavaScript를 바탕으로 동작한다.

### JavaScript의 현황

- JavaScript는 브라우저 안에서 시작했지만 Node.js의 등장으로 서버에서도 사용할 수 있게 됐다.
- Java와 Spring을 사용하는 기업이 많고 Node.js를 사용하는 스타트업이 많다는 말이 있지만 절대적인 기준은 아니다.
- ES6 이후 추가된 문법은 현재 JavaScript와 React 개발에서 자주 사용한다.

### 변수와 함수

- 변수는 값을 저장하는 이름이다.
- 기본값은 `const`로 선언한다.
- 다시 대입해야 할 때만 `let`을 사용한다.
- `var`는 함수 스코프와 호이스팅으로 동작을 예측하기 어려워 새 코드에서 피한다.
- 함수는 선언식과 표현식과 화살표 함수와 즉시 실행 함수로 작성할 수 있다.
- JavaScript에서 함수는 값처럼 전달할 수 있다.
- 콜백과 고차 함수와 클로저는 함수가 값이라는 특징에서 나온다.
- 일반 함수와 화살표 함수는 `this`를 결정하는 방식이 다르다.
