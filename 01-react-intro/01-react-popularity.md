# 1.1 리액트의 인기

## 높은 사용 수요

리액트는 프론트엔드 분야에서 높은 수요를 가진 기술이다.

- 생태계가 크기 때문에 필요한 자료를 찾기 쉽다.
- 사용자가 많아 개발 인력을 구하기 쉽다.
- 코드와 구조를 나누어 유지보수하기 좋다.
- 팀의 기술 스택을 통일하기 좋다.

특히 리액트와 함께 사용하는 **Next.js**가 널리 알려지면서 리액트를 선택하는 팀이 많아졌다.

## AI와 협업하기 좋은 구조

리액트는 AI를 활용한 코드 작성에도 비교적 잘 맞는 구조를 가지고 있다.

- 컴포넌트 단위로 코드를 나눌 수 있다.
- 자주 사용하는 패턴이 잘 정리되어 있다.
- 관련 자료와 오픈소스 코드가 많다.

이런 특징 덕분에 AI에게 특정 컴포넌트나 기능을 요청하고 결과를 수정하기 쉽다.

## 지속적인 발전

리액트는 Meta가 주도적으로 관리한다.
동시에 여러 기업과 오픈소스 커뮤니티가 함께 참여하고 있다.

핵심 API의 변화가 비교적 적고 기능을 점진적으로 추가하는 방식도 유지하고 있다.
따라서 기존 프로젝트를 유지하면서 새로운 기능을 단계적으로 도입하기 좋다.

## 핵심 정리

리액트는 높은 수요와 큰 생태계를 바탕으로 현재 프론트엔드의 대표적인 기술로 자리 잡았다.
