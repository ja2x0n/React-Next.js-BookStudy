# 1장 리액트(React)란

## 학습 범위

## 핵심 내용

리액트는 UI를 컴포넌트 단위로 나누어 관리하는 라이브러리다.

### 리액트가 성장한 이유

- 컴포넌트를 재사용할 수 있다.
- 큰 화면을 작은 단위로 나누어 관리할 수 있다.
- Virtual DOM으로 변경된 부분을 효율적으로 반영한다.
- Hooks를 사용해 함수 컴포넌트에서 상태와 생명 주기를 다룰 수 있다.
- 큰 생태계와 활발한 커뮤니티를 가지고 있다.

### 리액트가 등장한 배경

서비스가 커지면서 UI와 상태 관리가 복잡해졌다.
리액트는 컴포넌트 기반 설계와 Virtual DOM을 통해 이 문제를 해결하려 했다.
이후 함수 컴포넌트와 Hooks가 도입되면서 코드 재사용성과 가독성도 좋아졌다.

### 리액트의 한계

리액트는 UI에 집중하는 라이브러리다.
상태 관리와 라우팅과 데이터 요청 도구는 개발자가 직접 선택해야 한다.
이 과정에서 프로젝트의 자유도는 높아지지만 의존성과 구조적 복잡성도 커질 수 있다.

Virtual DOM도 모든 상황에서 성능 향상을 보장하지 않는다.
따라서 기술의 장점만 보지 말고 프로젝트의 목적과 사용 환경을 함께 고려해야 한다.
